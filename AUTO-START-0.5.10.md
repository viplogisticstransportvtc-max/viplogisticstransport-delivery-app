# V.I.P LOGISTICS TRANSPORT DELIVERY APP v0.5.10

- Windows startup launch is enabled with Electron `setLoginItemSettings`.
- The V.I.P Logistics Transport logo is used for the Windows app icon and window icon.
- Driver registration/login from v0.5.9 is retained.
- Automatic delivery start/completion is retained.

The app must be launched once after installation so Windows can register the per-user startup entry.
