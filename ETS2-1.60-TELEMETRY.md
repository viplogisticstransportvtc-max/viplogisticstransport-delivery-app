# ETS2 1.60 telemetry — v0.5.2

TruckTel is confirmed running on ETS2 1.60.1.7. The Delivery Client now treats TruckTel game/truck data as the connection source and does not fail just because optional job/frame data is temporarily unavailable.

Keep TruckTel running at http://127.0.0.1:8079/ and start the Delivery Client. The client should show ONLINE once it can read ETS2 game/truck telemetry.
