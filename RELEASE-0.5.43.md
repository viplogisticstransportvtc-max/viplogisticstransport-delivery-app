# Release v0.5.43

## Silent automatic update and automatic reopen

- Windows NSIS updates now use a one-click per-user installer.
- Automatic updates install silently without showing the installer wizard or requiring the driver to click Next.
- The application is configured to reopen automatically after the update finishes.
- Existing delivery state remains preserved by the backend during restart/update.
- No manual update action is required from the driver.
