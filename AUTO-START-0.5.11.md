# V.I.P LOGISTICS TRANSPORT DELIVERY APP v0.5.11

- Windows startup is enabled with the `--autostart` launch argument.
- When launched by Windows startup, the app opens and immediately minimizes to the taskbar.
- The app remains running in the background so ETS2/TruckTel automatic delivery detection continues.
- Manual START DELIVERY and COMPLETE/SUBMIT controls have been removed.
- Delivery start and completion are fully automatic from ETS2/TruckTel job state.
